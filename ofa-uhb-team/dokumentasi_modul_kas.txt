## 1. CARA MENJALANKAN PROGRAM

### 1.1 Persyaratan Sistem
- PHP 8.1+
- Node.js 20.19+ (untuk build frontend)
- MySQL/MariaDB
- XAMPP (direkomendasikan)
- Composer

### 1.2 Langkah-Langkah Menjalankan

**Langkah 1: Install Dependencies PHP**
```bash
cd d:/Project Laravel/kas/ofa-uhb-team
composer install
```

**Langkah 2: Install Dependencies Node.js**
```bash
npm install
npm run build
```
*Catatan: Jika error Node.js version, upgrade Node.js ke v20.19+ atau v22*

**Langkah 3: Buat Database**
1. Buka phpMyAdmin (http://localhost/phpmyadmin)
2. Buat database baru: `ofa-uhb-team`
3. Import file SQL jika ada, atau biarkan kosong

**Langkah 4: Konfigurasi Environment**
```bash
cp .env.example .env
```
Edit file `.env`:
```
DB_DATABASE=ofa-uhb-team
DB_USERNAME=root
DB_PASSWORD=

SESSION_DRIVER=database
CACHE_DRIVER=file
```

**Langkah 5: Generate Application Key**
```bash
php artisan key:generate
```

**Langkah 6: Jalankan Migration**
```bash
php artisan migrate
```

**Langkah 7: Seed Database (Opsional)**
```bash
php artisan db:seed
```

**Langkah 8: Jalankan Server**
```bash
php artisan serve
```
Buka browser: http://127.0.0.1:8000

## 3. FITUR YANG DITAMBAHKAN: MODUL MANAJEMEN KAS

### 3.1 Kas Masuk

**Deskripsi:** Mengelola data kas masuk/pemasukan.

**Fitur:**
- Melihat daftar kas masuk dengan filter (search, fakultas, tanggal)
- Menambah kas masuk baru (jumlah, tanggal, keterangan)
- Edit kas masuk
- Hapus kas masuk
- Detail kas masuk

**Akses Role:**
- Super Admin: Semua fitur
- Admin Kas FST/FIS: Hanya data fakultasnya
- Kepala Unit: View only

**Route:** `/kas/masuk`

---

### 3.2 Kas Keluar

**Deskripsi:** Mengelola data kas keluar/pengeluaran.

**Fitur:**
- Melihat daftar kas keluar dengan filter
- Menambah kas keluar baru
- Edit kas keluar
- Hapus kas keluar
- Detail kas keluar

**Akses Role:**
- Super Admin: Semua fitur
- Admin Kas FST/FIS: Hanya data fakultasnya
- Kepala Unit: View only

**Route:** `/kas/keluar`

---

### 3.3 Tagihan Dosen

**Deskripsi:** Mengelola tagihan kas untuk dosen per bulan.

**Fitur:**
- Melihat daftar tagihan dengan filter (status, bulan, tahun, fakultas)
- Menambah tagihan baru (pilih dosen, bulan, tahun, jumlah)
- Membayar tagihan (bayar partial atau lunas)
- Hapus tagihan
- Status otomatis berubah menjadi "Lunas" saat lunas

**Alur Kerja:**
1. Admin membuat tagihan untuk dosen tertentu
2. Dosen/pihak lain melakukan pembayaran
3. Admin memproses pembayaran melalui tombol "Bayar"
4. Sistem otomatis membuat transaksi kas masuk dan update status

**Akses Role:**
- Super Admin: Semua fitur
- Admin Kas FST/FIS: Hanya data fakultasnya
- Kepala Unit: View only

**Route:** `/kas/tagihan`

---

### 3.4 Laporan Kas

**Deskripsi:** Menampilkan rekapitulasi kas per bulan.

**Fitur:**
- Ringkasan total kas masuk, kas keluar, dan saldo
- Rekapitulasi per bulan (Januari - Desember)
- Filter berdasarkan tahun dan fakultas
- Saldo berjalan per bulan

**Akses Role:**
- Super Admin: Semua data
- Admin Kas FST/FIS: Hanya data fakultasnya
- Kepala Unit: View only

**Route:** `/kas/laporan`

## 4. STRUKTUR DATABASE

### Tabel: kas_transactions

| Kolom | Tipe | Deskripsi |
|-------|------|----------|
| id | bigint | Primary key |
| jenis | enum | 'masuk' atau 'keluar' |
| jumlah | decimal(12,2) | Nominal transaksi |
| tanggal | date | Tanggal transaksi |
| keterangan | text | Keterangan/transaksi |

## 7. TROUBLESHOOTING

### Error: "Vite manifest not found"
```bash
npm install
npm run build
```
Atau upgrade Node.js ke versi 20.19+

### Error: "Class not found"
```bash
composer dump-autoload
```

### Error Migration:
```bash
php artisan migrate:rollback
php artisan migrate
```

### Clear Cache:
```bash
php artisan config:clear
php artisan cache:clear
php artisan view:clear
```
